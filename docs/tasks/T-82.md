### Bug

- **Milestone status READ trả number** (root cause chung get_milestone + list_milestones):
  - create_milestone ghi `status: 0` numeric (T-67 #75, MilestoneStatus.Planned=0).
  - get_milestone đọc raw `status: (m as {status?:string}).status` → runtime = number 0.
  - list_milestones `status: ... ?? "planned"` — **dead code**: `0` không nullish →
    fallback KHÔNG bao giờ chạy. LLM nhận `status: 0` thay `"planned"`.
  - T-72 chỉ fix WRITE path (`stringToMilestoneStatus` string→number). Thiếu reverse
    map number→string cho READ.
- **list_persons** dead field `p.email`:
  - `email: (p as {email?:string}).email` — `Person.email` KHÔNG tồn tại. Email lives
    trong Channel attachedTo Person.
  - T-74 đã fix y hệt cho list_employees (drop email). list_persons còn sót.
- **update_user_profile** wrong target + phá format:
  - Ghi `contact.class.Person.name` thay vì account profile (`WorkspaceClient.setMyProfile`).
  - Huly `Person.name` = `"LastName,FirstName"` (trusted formatName/parseName). Set raw
    `params.name` → phá format, subsequent parse firstName/lastName sai.
  - Trusted `updateUserProfile` KHÔNG đụng Person.name (dùng account-client setMyProfile
    cho bio/city/country/website/socialLinks/isPublic).
