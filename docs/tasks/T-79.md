## Vấn đề (reality-checker CONFIRMED)

Toàn bộ 7 todos tool sai data model. 2 root cause:

1. **Giả định `done` boolean** — Huly ToDo dùng `doneOn: Timestamp | null`
   (completion = timestamp, KHÔNG flag).
2. **Không biết `ProjectToDo` class** — issue-attached todo là class riêng
   `time.class.ProjectToDo` (KHÔNG base `ToDo`).

Data model chuẩn (verified `@hcengineering/time` index.d.ts + trusted `planner.ts`):
- `ToDo extends AttachedDoc`: `doneOn`, `user: Ref<Employee>`, `priority(ToDoPriority)`,
  `workslots`, `attachedSpace`, `title`, `description(Markup)`, `dueDate`, `rank`, `labels`
- `ProjectToDo extends ToDo` → class `time:class:ProjectToDo`
- `Todoable.todos` = `CollectionSize<ToDo>` = **number counter** (KHÔNG array!)
- `time.space.ToDos` = space chung cho mọi todo
- ToDoPriority: High=0, Medium=1, Low=2, NoPriority=3, Urgent=4

### Bug từng tool

- **list_todos**: đọc `issue.todos` là array `(issue.todos ?? [])` — thực ra
  CollectionSize counter. Output `Found undefined todo(s)`, luôn sai/trống.
- **get_todo**: trả field `done` (boolean) — KHÔNG tồn tại. Thật `doneOn`.
- **create_todo**: (1) class `TODO_CLASS` (ToDo) thay `ProjectToDo` cho issue todo;
  (2) space `issue.space` thay `time.space.ToDos`; (3) thiếu `doneOn: null`;
  (4) description = `JSON.stringify(mdToMarkup)` thay Markup ref (uploadMarkup);
  (5) data thừa `attachedTo`/`attachedToClass` (do addCollection param gán);
  (6) `rank=""` hardcode thay `latestOpenTodoRank`.
  - priority map (high:0/medium:1/low:2/no-priority:3/urgent:4) **ĐÚNG** ✓
- **complete_todo**: `{ done: true }` — KHÔNG tồn tại → **no-op** (silent data loss).
  Thật `{ doneOn: <timestamp> }`.
- **reopen_todo**: `{ done: false }` — **no-op**. Thật `{ doneOn: null }`.
- **delete_todo**: `safeRemoveDoc(TODO_CLASS)` sai class (phải ProjectToDo) +
  KHÔNG `$inc { todos: -1 }` trên parent Issue → counter drift vĩnh viễn.

## Fix

### `_class-refs.ts`
- Add `PROJECT_TODO_CLASS = classRef("time:class:ProjectToDo")`
- Add `TODOS_SPACE = spaceRef("time:space:ToDos")`
- TODO_CLASS đã có (base class, dùng cho personal todo + list)

### `todos.ts`
- **list_todos**: query `findAll(TODO_CLASS, { attachedTo: issue._id })` (KHÔNG
  đọc `issue.todos` array). Hoặc cast CollectionSize đúng.
- **get_todo**: trả `doneOn` + derive `done = doneOn !== null`.
- **create_todo**: class `PROJECT_TODO_CLASS`, space `TODOS_SPACE`, data có
  `doneOn: null`, bỏ `attachedTo`/`attachedToClass` khỏi data, description qua
  `uploadMarkup`.
- **complete_todo**: `safeUpdateDoc(TODO_CLASS, t, { doneOn: Date.now() })`.
- **reopen_todo**: `safeUpdateDoc(TODO_CLASS, t, { doneOn: null })`.
- **delete_todo**: `safeRemoveDoc(PROJECT_TODO_CLASS, t)` + dec parent counter
  `safeUpdateDoc(ISSUE_CLASS, parent, { $inc: { todos: -1 } })`.
