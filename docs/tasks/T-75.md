## Vấn đề (reality-checker CONFIRMED)

- add_attachment/add_issue_attachment: gán inline `data` (field KHÔNG tồn tại) +
  createDoc thay addCollection + field `contentType` (thật `type`). Attachment
  created broken/empty.
- download_attachment: đọc field `data` (KHÔNG tồn tại) → always empty.
- Huly Attachment thật: `file: Ref<Blob>`, `name`, `size`, `type`, `lastModified`.

## Fix

### StorageClient wired (client.ts + types stub)
- Import `connectStorage`/`StorageClient` from @hcengineering/api-client (installed).
- Add optional `uploadBlob`/`getBlob` to HulyClient interface.
- createHulyClient: pass `getStorage` factory (lazy connectStorage) to makeWsClient/
  makeRestClient. Lazy connect on first blob op.
- Ambient stub `types/hcengineering.d.ts`: declare StorageClient + connectStorage.

### add_attachment / add_issue_attachment
- base64 → Buffer (strip data: URL prefix).
- `uploadBlob(filename, buffer, contentType)` → {blobId, size}.
- `addCollection` (KHÔNG createDoc) với {name, file: blobId, size, type, lastModified}.
- Field `type` (KHÔNG contentType), no `data`.
- attachedToClass param (generic, default ISSUE_CLASS) for add_attachment.

### download_attachment
- `getBlob(att.file)` → Buffer → base64.
- Return {name, type, size, data}. (KHÔNG đọc field `data` — used storage.)

### list_attachments / get_attachment
- Read field `type` (KHÔNG contentType).
