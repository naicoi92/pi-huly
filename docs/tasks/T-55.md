## Vấn đề

Lần gọi tool đầu tiên trong mỗi session luôn fail vì connection chưa sẵn sàng.
Pi-huly dùng **lazy connect** — WebSocket chỉ được tạo khi tool đầu tiên gọi
`getClient()` trong `builder.ts` (`execute()` step 3). Session start không warm
pool → cold start delay/fail.

## Phương án (fire-and-forget warm)

Subscribe `pi.on("session_start", ...)` trong `src/index.ts`, fire-and-forget
warm pool cho workspace đầu tiên trong credentials (`loadCredentials()`).

Bounds:
- **KHÔNG block startup** — `void warmPool()` (KHÔNG await trong subscribe).
- **Skip im lặng nếu chưa init** — `NeedsInitError` / credentials rỗng → no-op.
- **KHÔNG crash nếu warm fail** — try/catch swallow (lần gọi tool đầu tiên retry lazy).
- **Tuân thủ pool LRU** — qua `getClient(workspace)` (KHÔNG bypass pool, D14 shared).
- **Chỉ warm khi reason ∈ {startup, resume}** — skip reload (pool dev-reload còn
  reuse) + new/fork (user chủ động tạo session mới).
