1. **Class registry dump**: `findAll(core:class:Class, {})` → list tất cả class
   tồn tại. Cross-check 3 class ref với list.
2. **Direct probe từng class**:

### Hành vi end-to-end cần đạt

1. Trên self-host Huly thật (`@hcengineering/*@0.7.423`), xác nhận 3 class ref
   trên có tồn tại trong class registry runtime.
2. Nếu **tồn tại đúng** → thêm regression test runtime (snapshot class registry,
   gọi `findOne(CLASS, {})` không lỗi).
3. Nếu **sai domain/class** → tìm đúng ref, cập nhật `_class-refs.ts`, cập nhật
   `docs/design/11-runtime-audit.md` truth table.

   riêng hay inline. Nếu inline → refactor `add/remove/list_issue_relation` dùng
