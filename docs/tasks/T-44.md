## Phương án

### 1. Verify class refs (T-43 input) — quan trọng nhất vì scope đã nổ từ 2 → 6+

- **Query Huly model registry server-side**: dùng `@hcengineering/api-client`
  query `core:class:Class` (metadata table chứa toàn bộ class registry) →
  `findAll(Class, {})` → dump list tất cả class tồn tại trên self-host `workvps`.
  Cross-check từng class trong `_class-refs.ts` với list này.
- **Check plugin/extension install trên self-host**: Employee/Label/Tag có thể
  đến plugin chưa enable. Inspect Huly workspace config, list installed plugins.
  Pattern "sibling works" (Person ✓ / Employee ✗ trong cùng package) gợi ý mạnh
  plugin thiếu.
- **Re-verify từ npm packages**: download `@hcengineering/{contact,tracker,
  tags,view,document}` về, tìm constant class thật (vd
  `import { employeeId } from '@hcengineering/contact'`). Lưu ý: class refs
  thường KHÔNG phải string literal trong lib compiled — Huly generate qua
  model bundle, cần inspect `model.ts` hoặc test import.

### 2. Viết smoke test runtime (script hoặc integration test)

Connect Huly self-host thật, thực thi:

- `findOne(<each class>, {_id: <known hoặc any>})` cho mọi class trong
  `_class-refs.ts` → assert không "domain not found" (cover cả class "working"
  làm baseline + class "broken")
- Test `$like` operator với exact substring → assert match hoặc document fail
- Dump 1 issue có description dài (vd LST-1), inspect field `description` thật
  (string? ref? markup?) → determine storage model
- Inspect issue `labels` field thật → determine ref shape (`string _id` vs
  object `{ _id, ... }`) — cần cho T-45 (#27 add/remove_issue_label)
- Test `addCollection(TODO_CLASS, space, issueId, ISSUE_CLASS, "todos", doc)`
  với nhiều signature variant → reproduce `platform:status:UnknownError`
  và find correct form (cần cho T-46 #28)

### 3. Document findings trong `docs/design/`

(new ADR hoặc append `05-data-model.md`):

- **Class registry truth** (full dump từ Huly runtime — version Huly nào,
  class nào đúng/sai, plugin nào thiếu)
- Description storage model (inline vs ref document)
- Search capability thật (fulltext endpoint tồn tại? `$like` work?)
- Label ref shape (`string _id` vs object)
- Todo storage model (collection riêng vs embedded mixin) + addCollection
  protocol đúng
