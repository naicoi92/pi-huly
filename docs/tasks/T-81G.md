## Vấn đề

Tools chạy đúng storage (sau T-81 fix bug) nhưng output nghèo / thiếu fields vs
trusted. 8 gaps — KHÔNG break, chỉ thiếu capability.

### Gaps (vs trusted)

- **get_project**: thiếu `defaultStatus` + `statuses[]` inline (convenience — có
  list_statuses tool riêng)
- **list_projects**: không archived-filter default (trả cả archived); output chỉ
  `{identifier, name}` thiếu `description`/`archived`/`total`; thiếu sort + limit
- **update_project**: không support `description: null` clear
- **list_spaces**: không archived-filter; output nghèo (thiếu `class`/`type`/
  `privacy`/`memberCount`/`ownerCount`)
- **get_space**: chỉ resolve theo `_id`, không name-fallback + ambiguous handling
- **update_space**: thiếu 3 fields `private`, `archived`, `autoJoin` (trusted có 5,
  pi-huly có 2)
- **get_component**: lead trả raw Ref (không resolve Person name); description raw
  (không markdown); không label resolution (_id OR label)
- **set_issue_component**: không label-resolve; không support `null` clear

## Fix

### `projects.ts`

- list_projects: archived-filter default (exclude), sort name asc, limit; widen output
  (description, archived, total)
- get_project: add defaultStatus + statuses[] inline
- update_project: `description: Type.Union([Type.String(), Type.Null()])` + null clear

### `spaces.ts`

- list_spaces: archived-filter default; widen output (class, type, privacy, counts)
- get_space: name-fallback resolution (_id trước → exact name → ambiguous error)

### `components.ts`

- get_component: resolve lead→Person name, description→markdown, label OR `_id` resolve
- set_issue_component: label-resolve + `component: Type.Union([Type.String(), Type.Null()])`
