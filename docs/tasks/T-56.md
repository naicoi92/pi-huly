## Vấn đề

Khi Huly tool được gọi, user không thấy tool nhận params gì → khó debug khi tool
trả kết quả bất ngờ. `builder.ts:execute()` nhận `_toolCallId` + `_onUpdate`
(prefix `_` = unused). Không có log production code.

## Phương án (subscribe tool_execution_start)

Subscribe `pi.on("tool_execution_start", ...)` trong `src/index.ts`, log
`[huly_<tool>] args: <json>` ra **stderr** qua `console.error`.

**Stderr choice**: pi TUI hiển thị stderr nhưng JSON/print mode (headless
LLM-only) KHÔNG parse thành output → an toàn cho programmatic consumer.

Filter + format:
- **Filter**: `toolName.startsWith("huly_")` — skip built-in tool (bash, read, ...).
- **Format**: `[huly_<tool>] args: <JSON.stringify(args)>` — 1 dòng, dễ grep.
- **Truncate**: JSON > 500 chars → slice + `... (truncated, N chars total)`.
  **Order**: stringify → truncate → sanitize (code-review MINOR #1) — đảm bảo
  sanitize luôn chạy sau cùng, không secret lọt qua vì truncate cắt giữa.
- **Sanitize**: `sanitize()` từ `client/errors.ts` (LEAK_PATTERNS) strip
  token/secret trước khi log.
- **Circular safe**: try/catch `JSON.stringify` → `<unserializable>` fallback.
