## Vấn đề

`src/tools/domains/todos.ts:105-116` — `create_todo` crash với
`platform:status:UnknownError` khi `addCollection`. `list_todos` trên cùng issue
return 0 sạch → class `task:class:Todo` recognized, chỉ **create** fail. Vấn đề
ở signature/protocol call.

```ts
const id = await tctx.client.addCollection(
  TODO_CLASS,           // "task:class:Todo" — recognized, không "domain not found"
  issue.space as never,
  issue._id as never,
  ISSUE_CLASS,
  "todos",              // ← collection field có đúng không?
  { title, description, dueDate },   // ← missing required field?
);
```

`platform:status:UnknownError` từ Huly server quá generic — khó debug. Khả năng:

1. Class sai package (Todo có thể thuộc `tasks` thay `task`).
2. Collection field sai (`"todos"` vs `"items"` vs khác).
3. Missing required field (`attachedTo`? `space`? `owner`?).
4. addCollection signature mismatch với protocol version.

## Phương án (sau T-44 audit Todo model thật)

1. Dùng findings từ T-44 (Todo storage model + correct addCollection form).
2. Nếu Todo thực ra là **embedded mixin** (không phải collection riêng) → dùng
   `updateDoc($push)` thay `addCollection`.
3. Nếu là collection nhưng field/required khác → fix signature theo T-44 output.
4. Improve error wrapping: catch `platform:status:UnknownError` → log Huly
   server response chi tiết hơn để debug lần sau (cộng thêm context vào message).
