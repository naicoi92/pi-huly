### Pattern lạ quan trọng

Trong cùng package, class A works nhưng class B (sibling) broken:

- `contact:class:Person` ✓ NHƯNG `contact:class:Employee` ✗ (cùng package `contact`)
- `tags:class:TagCategory` ✓ NHƯNG `tags:class:Tag` ✗ (cùng package `tags`)
- `tracker:class:Issue/Project/IssueStatus/Milestone/Component/IssueTemplate` ✓ NHƯNG `tracker:class:TaskType` ✗ (cùng package `tracker`)

→ **Không phải package-level typo**. Khả năng: (a) class thực sự thuộc package
khác, (b) plugin chưa enable trên self-host (vd HR plugin cho Employee, view
plugin cho Label), hoặc (c) class name Huly đổi giữa version.
