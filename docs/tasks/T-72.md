  `uploadMarkup` + `ops.description = ref`.

### update_milestone status → enum
- Helper `stringToMilestoneStatus(s)` map: planned=0, in-progress=1, completed=2,
  canceled=3 (T-67 verified). Invalid → isError.

### update_issue status → scope project
- Thay `findAll(ISSUE_STATUS_CLASS, {})` global bằng `getProjectStatuses` (T-71
  reuse — ProjectType traversal). Match by _id exact trước, fallback name.
