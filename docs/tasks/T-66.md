## Data model (verified trusted)

- **Teamspace**: findAll `document:class:Teamspace` (chỉ trả Teamspace, không
  lẫn Project/Drive/ChunterSpace). CRUD space param = `core.space.Space` (root).
  Fields: name, description, private, archived.
- **Document**: findAll/findOne `document:class:Document` + `space=teamspace._id`.
  content = MarkupBlobRef → fetchMarkup (get) / uploadMarkup (create) /
  updateMarkup (edit khi blob tồn tại). edit 2 modes: full content replace
  OR search-and-replace (replace_all cho multiple matches).
- **DocumentSnapshot**: findAll `document:class:DocumentSnapshot` + `attachedTo=
  document._id`. content = MarkupBlobRef → fetchMarkup.
